Incident · 22 oktober 2021 · accountovername

ua-parser-js: een account te koop

Toegang

Het npm-account van de maintainer werd gekaapt. Hoe precies is niet bevestigd; twee weken eerder bood iemand op een Russisch forum een npm-account met “7 million installations” te koop aan.

Verspreiding

Drie kwaadaardige versies tegelijk (0.7.29, 0.8.0, 1.0.0), één per actieve versielijn, binnen de bestaande ranges van ~7,5 mln downloads per week.

Payload

Install scripts installeerden een cryptominer op Windows en Linux, en op Windows ook een steler van wachtwoorden en cookies.

Detectie en respons

Ongeveer vier uur online. Gebruikers meldden het op GitHub, CISA gaf dezelfde dag een waarschuwing. De maintainer kreeg eerst honderden spammails.

Les. Een gekaapt account plus een install script betekent binnen enkele uren code op miljoenen machines.

Had dit tegengehouden

cooldown, install scripts blokkeren

Deel 4 — Tijdlijn en casestudies · 0:18–0:30

Verdieping: sla over bij tijdgebrek. ua-parser-js leest de user-agent-string van een browser uit en had in oktober 2021 ongeveer 7,5 miljoen downloads per week. Op 22 oktober verschenen drie kwaadaardige versies, één in elke actieve versielijn, zodat vrijwel elke range ze oppikte. Het install script downloadde per besturingssysteem binaries: een Monero-cryptominer en op Windows een steler die wachtwoorden en browsercookies buitmaakte. Toegang: het account van de maintainer, Faisal Salman, werd gekaapt. Hij schreef: “my email was suddenly flooded by spams from hundreds of websites … I believe someone was hijacking my npm account.” Zo’n spamvloed dient vaak om de beveiligingsmails van npm te begraven, al is dat hier niet bevestigd. Rapid7 vond twee weken eerder een advertentie op een Russisch forum voor een npm-account zonder 2FA met meer dan 7 miljoen installaties per week, voor 20.000 dollar. Een bewezen link is er niet. Na ongeveer vier uur waren er propere opvolgers. CISA bracht dezelfde dag een alert uit. Brug: dit is het incident waarna npm en GitHub serieus werk maakten van verplichte 2FA (zie coa en rc, twee weken later). Bronnen: CISA-alert; Rapid7; GitHub-advisory GHSA-pjwm-rvh2-c87w.
