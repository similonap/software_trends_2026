react-codeshift: een naam die een AI verzon

De naam

react-codeshift bestond niet. Een taalmodel smolt jscodeshift en react-codemod samen tot één verzonnen naam.

Verspreiding

De naam stond in één commit met 47 door een LLM gegenereerde Agent Skills, en verspreidde zich via forks naar 237 repositories, zelfs vertaald naar het Japans.

Wat kon er gebeuren

Wie de naam eerst registreerde, kreeg code-uitvoering bij elke agent die de skill volgde en npx react-codeshift uitvoerde. Er is geen schade gemeld.

Wie het opmerkte

Charlie Eriksen van Aikido registreerde de naam defensief. Nog steeds komen er elke dag downloads binnen van agents die de skill volgen.

Les. Een AI-agent installeert zonder nadenken wat een andere AI verzonnen heeft. Controleer elke packagenaam.

Had dit tegengehouden

een agent in een sandbox, bevestiging voor installaties

Deel 7 — Geavanceerd en vooruitblik · 0:40–0:43

Verdieping: slopsquatting in het echt. Sla over bij tijdgebrek. Slopsquatting (deel 3) is typosquatting met namen die een AI-assistent verzint. Dit is het duidelijkste voorbeeld. Een taalmodel genereerde een reeks “Agent Skills”: instructiebestanden die een AI-agent vertellen hoe hij een taak uitvoert. In die skills stond npx react-codeshift. Dat package bestond niet: het is een samensmelting van twee echte tools, jscodeshift en react-codemod. De skills stonden in één commit met 47 skills en verspreidden zich via forks naar 237 repositories, zelfs vertaald naar het Japans. In januari 2026 registreerde Charlie Eriksen, onderzoeker bij Aikido, de naam defensief. Daarna kwamen er elke dag downloads binnen. Aikido: “Those are AI agents following skill instructions and triggering npx installs in real environments.” Had een aanvaller de naam eerst geregistreerd, dan had elke agent die de skill volgde zijn code uitgevoerd. Waarom dit gevaarlijk is: een mens die npm install react-codeshift typt, kijkt misschien nog even op npmjs.com. Een agent die een skill volgt, doet dat niet. Vuistregel: laat een agent geen packages installeren zonder bevestiging, en laat hem in een sandbox werken. Bron: Aikido, “Slopsquatting: AI package hallucination attacks”.
