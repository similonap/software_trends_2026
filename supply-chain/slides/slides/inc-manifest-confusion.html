Ontwerpfout · juni 2023 · de registry zelf

Manifest confusion: twee waarheden

De fout

Bij het publiceren stuur je de metadata los van de tarball mee. De registry controleerde niet of die metadata klopte met de package.json in de tarball.

Waarom het ertoe doet

npmjs.com, scanners en tools lezen de metadata; de installer gebruikt de tarball. Wat je op de website ziet, is dus niet per se wat je installeert.

Wat kon er gebeuren

Install scripts en dependencies die nergens vermeld staan, maar toch meekomen en draaien. Het gedrag verschilt per client en per versie.

Detectie en respons

Darcy Clarke, oud-engineering manager van npm, maakte het in juni 2023 publiek, nadat GitHub zijn melding “intern” afhandelde. Het was al sinds november 2022 bekend.

Les. Vertrouw de tarball, niet de metadata: kijk naar wat een package bevat, niet naar wat het over zichzelf zegt.

Had dit tegengehouden

install scripts blokkeren, een scanner die de tarball leest

Deel 4 — Tijdlijn en casestudies · 0:18–0:30

Verdieping: sla over bij tijdgebrek. Geen aanval, maar een ontwerpfout die elk package raakte. Wanneer je npm publish uitvoert, stuurt de CLI twee dingen naar de registry: de tarball met je code en daarnaast een “manifest” met metadata (naam, versie, dependencies, scripts). Darcy Clarke, voormalig engineering manager van het npm CLI-team, toonde in juni 2023 dat de registry niet controleerde of die metadata overeenkwam met de package.json in de tarball: “The npm Public Registry does not validate manifest information with the contents of the package tarball.” Gevolg: de website en veel securitytools lezen de metadata en zien bijvoorbeeld geen install script, terwijl de tarball er wel een bevat. Afhankelijk van de client (npm 6, npm 9 offline, Yarn 1, pnpm 7) draaide zo’n verborgen script of kwam een niet-vermelde dependency mee. GitHub wist het sinds november 2022. Clarke meldde het in maart 2023 via HackerOne, GitHub sloot de melding met de boodschap dat het intern werd afgehandeld, en daarna maakte hij het publiek. De les komt terug bij PhantomRaven en @joyfill: wat npmjs.com toont, is niet altijd wat er op je schijf belandt. Bronnen: Darcy Clarke (vlt.io); The Register, 27 juni 2023.
