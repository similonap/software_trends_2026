Incident · 22 maart 2016 · beschikbaarheid

left-pad: elf regels die het internet braken

Toegang

Geen aanval. Na een naamsconflict over zijn package kik, dat npm in het voordeel van het bedrijf Kik besliste, verwijderde Azer Koçulu al zijn 273 packages.

Verspreiding

Builds haalden left-pad live van de registry, meestal transitief, onder meer via Babel. Was het package weg, dan faalde elke installatie.

Effect

Geen kwaadaardige code, wel wereldwijd gebroken builds. npm zag “hundreds of failures per minute”. De vrijgekomen namen kon bovendien iedereen claimen.

Detectie en respons

Binnen tien minuten publiceerde iemand een kopie; npm zette versie 0.0.3 na 2,5 uur terug. Sindsdien is unpublishen beperkt.

Les. Een build die live van de registry afhangt, hangt af van de goodwill van elke maintainer in de boom.

minder dependencies, een eigen mirror

Deel 4 — Tijdlijn en casestudies · 0:18–0:30

Verdieping: sla over bij tijdgebrek. Dinsdag 22 maart 2016. Azer Koçulu had een package met de naam kik. Het bedrijf achter de berichtenapp Kik wilde die naam, en npm gaf het bedrijf gelijk. Uit protest verwijderde Koçulu al zijn 273 packages, waaronder left-pad: elf regels code die een string links aanvullen met spaties. left-pad werd in de vier weken ervoor ongeveer 2,45 miljoen keer gedownload, meestal als transitieve dependency. Builds wereldwijd braken, ook die van grote projecten zoals Babel en React. npm zag “hundreds of failures per minute”. Binnen tien minuten publiceerde Cameron Westland een identieke versie 1.0.0, en npm zette na ongeveer 2,5 uur de oorspronkelijke versie 0.0.3 terug uit een backup. Les van npm zelf: “Unrestricted un-publishing caused a lot of pain.” Sindsdien geldt: unpublishen mag binnen 72 uur als niemand van het package afhangt, daarna alleen bij geen dependents, minder dan 300 downloads per week en één eigenaar. Vraag aan de zaal: helpt een lockfile hier? Nee: de lockfile wijst naar een tarball die niet meer bestaat. Wat wel helpt, is een eigen mirror of proxy-registry, of het package gewoon niet nodig hebben (vandaag doet String.prototype.padStart hetzelfde). Bronnen: npm-blog “kik, left-pad, and npm”; npm unpublish policy.
