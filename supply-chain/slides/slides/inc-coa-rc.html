Incident · 4 november 2021 · accountovername

coa en rc: de malware brak zichzelf

Toegang

Gecompromitteerde npm-accounts. Hoe precies is niet publiek bevestigd. coa had sinds december 2018 geen nieuwe versie meer gekregen.

Verspreiding

Nieuwe versies in elke versielijn, samen ~24 mln downloads per week. coa zat transitief in de React-toolchain, via svgo in react-scripts.

Payload

Een preinstall-script startte op Windows een batchbestand dat een DLL downloadde, vermoedelijk de wachtwoordsteler DanaBot. Bijna dezelfde code als bij ua-parser-js.

Detectie en respons

Ontdekt omdat het script faalde en React-builds wereldwijd braken. Op 15 november kondigde GitHub verplichte 2FA aan voor populaire packages.

Les. Een package dat drie jaar stil lag en plots nieuwe versies krijgt, is een alarmsignaal.

Had dit tegengehouden

cooldown, install scripts blokkeren

Deel 4 — Tijdlijn en casestudies · 0:18–0:30

Verdieping: sla over bij tijdgebrek. Twee weken na ua-parser-js, op 4 november 2021, verschenen kwaadaardige versies van coa (een parser voor command-line opties, ~9 miljoen downloads per week) en rc (configuratiebestanden lezen, ~15 miljoen per week). coa had sinds december 2018 geen release meer gehad. De payload zat in een preinstall-script en downloadde op Windows een DLL, vermoedelijk de wachtwoordsteler DanaBot. De code leek sterk op die van ua-parser-js. Ironisch: het script faalde op veel systemen, waardoor CI-pipelines en React-builds wereldwijd braken. Zo werd de aanval snel opgemerkt. Een slordige aanvaller is een snel ontdekte aanvaller; de aanvallers van 2025 en 2026 testen hun code beter. Respons: npm verwijderde de versies. Op 15 november 2021 kondigde GitHub aan dat maintainers van populaire packages 2FA moesten gebruiken, te beginnen in het eerste kwartaal van 2022. Dat is de overgang naar fase 2 op de tijdlijn. Les voor gebruikers: een nieuwe versie van een package dat jarenlang stil lag, verdient wantrouwen. Een cooldown van een paar dagen had dit opgevangen. Bronnen: GitHub-advisories GHSA-73qr-pfmq-6rp8 (coa) en GHSA-g2q5-5433-rhrf (rc); BleepingComputer; GitHub-blog over verplichte 2FA.
