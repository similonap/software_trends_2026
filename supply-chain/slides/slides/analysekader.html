Deel 3 — Het dreigingsmodel · 0:12–0:18

We ontleden elk incident in deel 4 met dezelfde vier vragen: 1. Toegang: hoe kreeg de aanvaller de macht om code in de keten te brengen? 2. Verspreiding: hoe bereikte die code de slachtoffers? 3. Payload: wat deed de code eenmaal ze draaide? 4. Detectie en respons: wie merkte het op, hoe snel, en wat veranderde er daarna? Studenten gebruiken dit kader ook in oefening 2 (incidentanalyse van één pagina). Het is meteen de structuur van een goed incidentrapport in de praktijk.
