Deel 2 — Hoe npm werkt · 0:05–0:12

“npm” is eigenlijk drie dingen: de registry (registry.npmjs.org, sinds 2020 eigendom van GitHub en dus Microsoft), de CLI die je lokaal draait, en de website. Alternatieve package managers zoals pnpm, Yarn en Bun gebruiken dezelfde registry. Een package is een tarball (.tgz) met code plus metadata uit package.json: naam, versie, dependencies en scripts. Een package kan een scope hebben, zoals @angular/core: een namespace die aan één gebruiker of organisatie toebehoort. Packages zonder scope delen één globale naamruimte waarin geldt: wie eerst komt, eerst maalt. Dat is belangrijk voor typosquatting en dependency confusion in deel 3. Het belangrijkste ontwerpprincipe: iedereen mag publiceren, zonder voorafgaande review.
