Deel 5 — Verdediging als gebruiker · 0:30–0:36

Dit is de maatregel met de grootste impact, en de ecosystemen hebben ze in 2025–2026 eindelijk standaard gemaakt. npm 12 (8 juli 2026) blokkeert install scripts van dependencies, inclusief de impliciete node-gyp-build, tenzij ze in de allowScripts-lijst van je root-package.json staan. Je keurt een package goed met npm install-scripts approve en de naam (op npm 11.16 en 11.17 heette dat npm approve-scripts; die naam werkt nog als alias); strict-allow-scripts=true maakt een niet-goedgekeurd script een harde fout. Daarnaast weigert npm 12 standaard dependencies die rechtstreeks uit een Git-repository of van een willekeurige URL komen (allow-git en allow-remote staan op none). Dat sluit de truc van PhantomRaven. pnpm voert sinds versie 10 (januari 2025) geen install scripts van dependencies meer uit zonder toestemming. Yarn zet sinds 4.14 (april 2026) enableScripts standaard uit. Bun voert al jaren alleen scripts uit van trustedDependencies. Werk je nog met npm 10 of 11, zet dan ignore-scripts=true in .npmrc en gebruik eventueel @lavamoat/allow-scripts voor een allowlist. Let op: ignore-scripts blokkeert ook de scripts van je eigen project, zoals de prepare-hook van husky. Op npm 12 gebruik je beter allowScripts. De kanttekeningen: code die pas bij import of in de browser draait, zoals bij chalk/debug of @joyfill in 2026, houd je hiermee niet tegen.
