Je pipeline beveiligen

Zes regels voor elke workflow

1 Geen pull_request_target

en nooit code uit de PR onder die trigger. Nx, PostHog, Trivy en TanStack vielen hierdoor.

2 Invoer via env:

nooit via ${{ }} in een run-stap. Titels, branchnamen en comments zijn onvertrouwd.

3 Minimale permissions

contents: read als standaard; id-token: write alleen in de publicatiejob.

4 Pin Actions op een commit-SHA

niet op een tag. Bij tj-actions en Trivy werden bestaande tags gewoon verplaatst.

5 De cache is invoer

Onvertrouwde triggers schrijven geen cache die je release-workflow leest (TanStack).

6 Kijk mee

zizmor op je workflows, Harden-Runner op je runners, een melding bij elke publicatie.

Deel 6 — Verdediging als maintainer en in CI/CD · 0:36–0:40

De regels die je moet kennen. In de cursustekst staan er acht; deze zes zijn de kern. 1. Vermijd pull_request_target, en voer onder die trigger nooit code uit een pull request uit. 2. Geef onvertrouwde invoer door via env:, nooit via ${{ }} in een run-stap. 3. Least privilege: permissions standaard op contents: read, id-token: write alleen voor de publicatiejob. 4. Pin Actions op een volledige commit-SHA. GitHub kan SHA-pinning afdwingen via een beleid, en sinds 14 oktober 2026 bestaan workflow-lockfiles in public preview. 5. Behandel de cache als invoer. GitHub reageerde in juni 2026 op TanStack: de Actions-cache is alleen-lezen voor onvertrouwde triggers. 6. Kijk mee: zizmor analyseert workflows statisch op deze fouten, StepSecurity Harden-Runner bewaakt het netwerkverkeer van runners (zo werd tj-actions ontdekt). Axios en TanStack hadden geen alarm bij een onverwachte publicatie. De twee extra regels uit de tekst: bescherm publicatie met een environment met verplichte reviewers, en roteer secrets na een incident in één keer. Bij Trivy hield de aanvaller toegang omdat de rotatie gespreid verliep. Kernpunt deel 6: als maintainer bescherm je niet alleen jezelf, maar iedereen die van je afhangt. Phishing-resistente 2FA, trusted publishing zonder tokens, staged publishing en een beveiligde pipeline maken van jouw package een saai doelwit.
