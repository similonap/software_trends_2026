Deel 2 — Hoe npm werkt · 0:05–0:12

Install scripts zijn het bekendste moment, maar niet het enige. Wie alleen --ignore-scripts aanzet, is dus niet klaar. 1. Installatie: npm voert lifecycle scripts uit op je laptop of CI-runner. Op het spel: tokens, SSH-sleutels, cloudcredentials, broncode. 2. Build, test en lint: je bundler, testrunner en ESLint-plugins laden het package in. Dezelfde secrets, plus je build-output. Event-stream viel hier. 3. Runtime op de server: Node.js in productie. Klantdata en databasecredentials. 4. In de browser van je eindgebruiker: gebundelde frontendcode. Wallets, sessies, wat de gebruiker intypt. Chalk/debug viel hier. Vraag aan de zaal: welk moment is het moeilijkst te beschermen? (Antwoord: 3 en 4, want daar moet de code draaien om haar werk te doen.)
