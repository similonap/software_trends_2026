Deel 2 — Hoe npm werkt · 0:05–0:12

Demo van 3 minuten in een wegwerpcontainer met node:24. Nooit op je eigen laptop met echte tokens. 1. docker run --rm -it node:24 bash 2. npm init -y && npm install express --ignore-scripts 3. Lees in de output “added 65 packages” voor. 4. npm explain debug: toon waarom debug erin zit, ook al typte niemand die naam. 5. Open package-lock.json (volgende slide). Het aantal maintainers (36) bereken je op voorhand met een klein script over de lockfile en de registry-API, en je toont het op deze slide. Let op: npm view express maintainers geeft alleen de maintainers van express zelf, niet van de hele boom. Vraag aan de zaal: “Hoeveel van deze 36 mensen ken je?” Je typte één naam, maar je vertrouwt nu 36 mensen, hun wachtwoorden, hun laptops en hun CI-pipelines. Waarom --ignore-scripts? Zelfs in een demo voer je geen vreemde install scripts uit als dat niet nodig is.
