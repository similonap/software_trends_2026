Tijd om af te ronden: vijf trends in één slide. Eén: signals en compilers hebben gewonnen. Angular is volledig signal-first en zoneless, React heeft een stabiele compiler, Vue en Svelte laten de virtual DOM achter zich. Jij schrijft eenvoudigere code, de tooling doet het optimalisatiewerk. Twee: de server-slinger. Server-first frameworks proberen nu aan te voelen als een SPA, met Cache Components, streaming en Instant Navigations. Tegelijk is er een tegenbeweging met Remix 3, TanStack Start en Astro. Je kiest niet meer per app, maar per stukje UI: streamen, cachen of blokkeren. Drie: security. Server Actions zijn publieke endpoints, en React2Shell toonde dat een fout in de deserialisatie van het framework zelf tot remote code execution kan leiden. AI versnelt het vinden van lekken aan beide kanten, en de supply chain is een tweede aanvalsoppervlak. Een framework kiezen is ook een update-ritme kiezen. Vier: de agent als gebruiker. Frameworks bundelen hun documentatie voor agents in AGENTS.md, bieden MCP-servers en skills aan, en schrijven foutmeldingen die een agent kan oplossen. Tegelijk moet je agents beschermen tegen prompt injection. Wat goed is voor agents, is meestal ook goed voor mensen. Vijf: het AI-native web. Modellen beïnvloeden welke stack gekozen wordt, app builders maken apps voor iedereen, met de bijbehorende risico's, en websites krijgen nieuwe interfaces voor AI, zoals MCP Apps en WebMCP. De belangrijkste boodschap: blijf kritisch. Kritisch tegenover bedrijven die hun framework sturen, en kritisch tegenover de code die je AI-agent schrijft.
