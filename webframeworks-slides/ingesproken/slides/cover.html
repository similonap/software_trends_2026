Trends in JavaScript Web Frameworks

Academiejaar 2026–2027

Welkom bij deze les over trends in JavaScript web frameworks. Bijna elke webapplicatie die jullie later bouwen, of het nu een webshop, een intern dashboard of een SaaS-product is, wordt gemaakt met een framework zoals React, Angular, Vue of Svelte, vaak in combinatie met een meta-framework zoals Next.js of Nuxt. Die frameworks veranderen snel, en het is onmogelijk om elke nieuwe versie te volgen. Daarom focussen we vandaag niet op lijstjes met features, maar op de onderliggende concepten en de grote bewegingen erachter. We doen dat in twee lagen. Eerst leggen we de bouwstenen uit: hoe een webpagina gerenderd wordt, wat hydration is, wat server components zijn, wat signals zijn. Dat zijn de begrippen die je nodig hebt om de rest te begrijpen. Daarna bekijken we vijf trends die het voorbije jaar het landschap bepaald hebben. De rode draad daarin is AI: een groot deel van de code wordt vandaag geschreven door AI-agents, en frameworks passen zich daaraan aan. Let tijdens de presentatie op de slides met het woord Kernbegrip rechtsboven. Dat zijn de definities en concepten die je moet kennen en kunnen uitleggen. Achteraan vind je ook een begrippenlijst.
