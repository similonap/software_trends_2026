Eerst de cijfers. De Stack Overflow Developer Survey van 2026 verscheen begin oktober. Van de developers die AI-tools gebruiken, gebruikt drieënzeventig procent ze dagelijks. En van die dagelijkse gebruikers zit eenendertig procent meer dan vier uur per dag met AI-tools te werken. Dat is geen experiment meer, dat is de normale manier van werken. Belangrijker nog: coding agents worden nu door meer mensen gebruikt dan chatbots, zesenzestig tegenover drieënzestig procent. Het verschil is essentieel. Een chatbot geeft je een stukje code dat je zelf kopieert. Een agent leest je hele codebase, past bestanden aan, draait je build en je tests en itereert tot het werkt. Claude Code en GitHub Copilot zijn de meest gebruikte agents. Tegelijk zijn developers voorzichtig. Slechts twintig procent gebruikt AI om te deployen of productiesystemen te troubleshooten. En drieënnegentig procent zegt dat bronvermelding nodig is om AI-output te vertrouwen. Dit stemt overeen met wat we bij State of JS zagen: Claude verdubbelde, Cursor verdubbelde, ChatGPT daalde. Waarom is dit relevant voor web frameworks? Als het merendeel van de code door agents geschreven wordt, dan is de kwaliteit van die code afhankelijk van hoe goed de agent het framework kent. En daar zit een fundamenteel probleem, dat zie je op de volgende slide.
