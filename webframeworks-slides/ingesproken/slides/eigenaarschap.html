Volg het geld: wie betaalt, bepaalt mee de richting van een framework.

Bronnen: react.dev/blog, Cloudflare persbericht 16/01/2026, anthropic.com/news (03/12/2025)

9

Open source-frameworks zijn gratis, maar iemand moet de developers betalen die eraan werken. Wie dat is, beïnvloedt de keuzes die een framework maakt. Daarom: volg het geld. Er zijn grofweg twee modellen. In het eerste model zit een project in een foundation: een neutrale non-profitorganisatie waarin meerdere bedrijven samen beslissen. React is in februari 2026 overgedragen aan de React Foundation, onder de Linux Foundation. Meta, dat React ooit maakte, beslist dus niet langer alleen. Dat is goed voor de onafhankelijkheid. In het tweede model is een framework eigendom van een bedrijf dat er op een andere manier geld aan verdient, meestal met hosting. Vercel maakt Next.js en verdient geld wanneer je je app op hun servers draait. Sinds juli 2025 werkt ook het team achter Nuxt, het meta-framework voor Vue, bij Vercel. Cloudflare kocht in januari 2026 Astro. Anthropic, het bedrijf achter Claude, kocht de JavaScript-runtime Bun omdat zijn coding agent Claude Code daarop draait. VoidZero, het bedrijf achter Vite, lanceert een eigen hostingplatform. En Remix is al sinds 2022 van Shopify. Is dat slecht? Niet noodzakelijk: alles blijft open source en die bedrijven investeren veel. Maar als een framework een standaardkeuze maakt, bijvoorbeeld om meer op de server te draaien, is het gezond om je af te vragen wie daar baat bij heeft. Een hostingbedrijf verdient meer als jouw app meer serverrekenkracht nodig heeft. Een positief voorbeeld: onder druk van de community kreeg Next.js in 2026 een stabiele Adapter API, die het makkelijker maakt om ook buiten Vercel te deployen.
