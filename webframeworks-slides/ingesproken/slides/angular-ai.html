Angular 22 en AI-agents

  • Skills: angular-new-app en angular-developer, dé bron van Angular-kennis voor agents
  • MCP-server in de CLI: sinds v20.1; in v22 kleiner gemaakt omdat skills de kennis overnemen

Dit is geen verhaal van Next.js alleen. Angular volgt exact dezelfde strategie, met dezelfde mechanismen die we net zagen. Skills: met Angular 22 installeer je met één commando de officiële Angular-skills. Er zijn er twee: angular-new-app, om nieuwe projecten correct op te zetten, en angular-developer, voor het genereren van code en architectuurkeuzes. Volgens het Angular-team is die laatste dé bron van Angular-kennis voor agents. Daardoor genereert een agent moderne, signal-gebaseerde en zoneless code in plaats van de NgModules en constructor injection die in oudere trainingsdata domineren. MCP: de Angular CLI heeft sinds versie 20.1 een ingebouwde MCP-server. Opvallend: in versie 22 werden er tools uit verwijderd, zoals het zoeken naar voorbeelden en het moderniseren van code, omdat de skills die taak nu beter doen. Precies dezelfde beweging als bij Next.js: kennis via docs en skills, live informatie via MCP. En het derde punt is technisch mooi. In development stelt Angular de signal-graph, welke signal van welke andere afhangt, en de dependency injection-graph beschikbaar als tools in Chrome DevTools. Via de MCP-server van Chrome DevTools kan een agent die opvragen. Een agent die een bug zoekt, kan dus letterlijk zien welke waarden van welke andere afhangen, in plaats van te gokken. Angular 22 heeft ook experimentele ondersteuning voor WebMCP, maar dat bespreken we bij trend vijf.
