Derde punt: generative UI. Dat betekent dat een AI niet antwoordt met tekst, maar met een interactieve interface: een tabel, een kaart, een formulier, een boekingsscherm. Op 26 januari 2026 werd MCP Apps gelanceerd, de eerste officiële uitbreiding van het Model Context Protocol dat we bij trend vier zagen. Het voegt twee bestaande initiatieven samen: het community-project MCP-UI en de Apps SDK van OpenAI. Kijk naar het schema. Een gebruiker vraagt in een chat-applicatie om vluchten naar Lissabon. De AI roept een tool aan op een MCP-server, bijvoorbeeld van een reisbureau. Die tool geeft niet alleen data terug, maar ook een UI-resource: een stukje HTML en JavaScript. De host, bijvoorbeeld ChatGPT, Claude of VS Code, toont die UI in een sandboxed iframe midden in het gesprek, en de gebruiker kan er rechtstreeks mee werken. Wat is een sandboxed iframe? Een iframe is een webpagina binnen een andere webpagina. Met het sandbox-attribuut krijgt die ingesloten pagina beperkte rechten: ze kan niet aan de cookies, de DOM of de data van de omliggende pagina. Communiceren kan alleen via postMessage, een browser-API om berichten tussen vensters te sturen. Zo kan een externe partij UI tonen in ChatGPT zonder dat die UI je gesprekken kan lezen. Voor clients die geen UI ondersteunen, is er altijd een tekstversie. Waarom is dit relevant voor web frameworks? Omdat die UI gewoon een webapplicatie is, gebouwd met React, Vue of web components. Je webapp krijgt er een nieuwe plek bij: in een chat-interface. Er ontstaan ook frameworks specifiek voor AI-interfaces: de AI SDK 6 van Vercel en TanStack AI, waarvan versie 1.0 op 23 oktober 2026 uitkwam.
