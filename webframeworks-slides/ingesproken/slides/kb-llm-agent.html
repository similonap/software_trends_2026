Wat is een taalmodel, en wat is het verschil met een coding agent? Een groot taalmodel, een large language model of LLM, is een neuraal netwerk dat getraind is op enorme hoeveelheden tekst en code. Het doet in essentie één ding: telkens het volgende stukje tekst voorspellen. Zo'n stukje noemen we een token, ongeveer een woorddeel. Door dat heel vaak na elkaar te doen, kan het hele programma's schrijven. Twee begrippen zijn belangrijk. De training cutoff: het model kent alleen wat in zijn trainingsdata stond, tot een bepaalde datum. Nieuwere versies van frameworks kent het niet. En het context window: alles wat het model op één moment kan ‘zien’, zoals je vraag, de bestanden die je meegeeft en de vorige berichten. Alles daarbuiten weet het niet. Een chatbot zoals ChatGPT in de browser werkt met vraag en antwoord. Het model ziet alleen wat jij erin plakt. Jij kopieert de code naar je project, test, en komt terug met de foutmelding. Een coding agent zet het taalmodel in een lus met tools. Tools zijn functies die het model mag aanroepen: een bestand lezen, een bestand aanpassen, een commando uitvoeren zoals npm test, of op het web zoeken. Kijk naar de lus onderaan. De agent leest het doel, maakt een plan, gebruikt een tool, bijvoorbeeld de tests draaien, leest het resultaat, en beslist wat de volgende stap is. Dat herhaalt hij tot de taak klaar is of hij vastloopt. Voorbeelden zijn Claude Code, Cursor, GitHub Copilot en Codex. Het belangrijke inzicht voor frameworks: een agent is zo goed als de informatie die hij kan zien. Wat niet in zijn trainingsdata of context zit, en wat hij niet via een tool kan opvragen, weet hij niet.
