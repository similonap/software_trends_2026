Begrippenlijst (2/3): DOM, virtual DOM en React

DOM: boom van objecten die de browser uit HTML maakt; JavaScript kan hem aanpassen

Reflow / repaint: layout herberekenen / pixels opnieuw tekenen na een DOM-wijziging

Declaratief: beschrijven wát er moet staan (UI = f(state)) in plaats van hoe de DOM verandert

Virtual DOM: boom van JS-objecten (type + props) die beschrijft hoe de UI moet zijn

Render- / commitfase: componenten uitvoeren en vergelijken / wijzigingen in de echte DOM zetten

Reconciliation: oude en nieuwe virtuele boom vergelijken in O(n) met heuristieken

Ander type: de hele deelboom wordt vervangen, state gaat verloren; bij een component is het type de functie zelf

key: unieke, stabiele id zodat React lijstitems herkent over renders heen

Re-render cascade: een parent rendert, dus alle kinderen renderen mee, ook bij gelijke props

Referentiële gelijkheid: objecten en functies zijn enkel gelijk als het hetzelfde object is

React.memo: render overslaan als alle props (shallow) gelijk zijn

useMemo / useCallback: waarde / functie onthouden zolang de dependencies gelijk blijven

React Compiler: voegt tijdens de build automatisch memoization toe (cache per component)

Rules of React: puur, immutable, hooks bovenaan; anders een bail-out van de compiler

De tweede begrippenlijst bundelt alles over de DOM, de virtual DOM en het optimaliseren van React. Een goede examenoefening is om deze begrippen in een logische volgorde aan elkaar te koppelen. Bijvoorbeeld: de DOM is duur om aan te passen door reflow en repaint. Daarom gebruikt React een declaratief model met een virtual DOM: bij elke state-wijziging voert React in de renderfase de componenten uit, vergelijkt het met reconciliation de nieuwe boom met de oude, met de regels ander type betekent vervangen en keys voor lijsten, en voert het in de commitfase enkel de verschillen uit. Een nadeel is de re-render cascade: kinderen renderen mee, ook als hun props gelijk zijn. React.memo kan dat vermijden, maar faalt door referentiële gelijkheid als je nieuwe objecten of functies doorgeeft; daarvoor zijn useMemo en useCallback nodig. De React Compiler doet dat allemaal automatisch, op voorwaarde dat je de Rules of React volgt.
