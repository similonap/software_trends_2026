De browser neemt framework-taken over

  • View Transitions: animaties tussen pagina’s en toestanden, native; basis van React’s <ViewTransition>
  • Navigation API: moderne vervanger van de History API voor client-side routing
  • Temporal: correcte datums en tijdzones (Firefox, Chrome 144, Node 26; Safari nog niet)
  • Anchor positioning: tooltips en menu’s in CSS aan een element vastmaken, zonder library
  • Dialog en popover: toegankelijke modals en popovers met enkel HTML
  • Scoped custom elements: twee versies van dezelfde web component op één pagina

Interop = jaarlijkse samenwerking van Apple, Google, Microsoft, Mozilla en Igalia om features in alle browsers gelijk te laten werken (2026: 20 focusgebieden). Baseline = label voor features die in alle grote browsers werken.

Een stille maar belangrijke trend: de browser zelf neemt steeds meer taken over waarvoor je vroeger een framework of library nodig had. Twee begrippen eerst. Interop is een jaarlijks samenwerkingsproject tussen Apple, Google, Microsoft, Mozilla en het bedrijf Igalia. Ze kiezen samen features die in alle browsers op exact dezelfde manier moeten werken, en meten de vooruitgang met duizenden automatische tests. In 2026 zijn er twintig focusgebieden. Baseline is een label dat aangeeft dat een feature in alle grote browsers werkt, zodat je ze zonder zorgen kan gebruiken. Een paar voorbeelden. View Transitions: animaties tussen pagina's of toestanden, rechtstreeks in de browser. Het ViewTransition-component van React is daar gewoon een laagje bovenop. De Navigation API: een moderne vervanger voor de History API die client-side routers gebruiken, met één centrale plek om alle navigaties op te vangen. Temporal: eindelijk een goede JavaScript-API voor datums en tijdzones, als vervanger van het beruchte Date-object. Firefox en Chrome ondersteunen het al, net als Node 26; Safari nog niet. Anchor positioning: in CSS een tooltip of dropdown vastmaken aan een ander element, iets waarvoor je vroeger een JavaScript-library nodig had. Dialog en popover: toegankelijke modals en popovers met alleen HTML. En scoped custom element registries: bij web components is de naam van een custom element globaal, waardoor twee versies van dezelfde component niet samen op één pagina konden. Scoped registries lossen dat op. De les: hoe meer het platform kan, hoe minder framework je nodig hebt. En webstandaarden veranderen niet elk kwartaal, dus ze staan ook correct in de trainingsdata van AI-modellen.
