Wat doet een build tool?

  • Transpileren: TypeScript en JSX omzetten naar gewone JavaScript
  • Bundelen: honderden modules samenvoegen tot enkele bestanden
  • Tree shaking: ongebruikte code weglaten
  • Minificeren: spaties en lange namen weghalen
  • Code splitting: per pagina een eigen bestand
  • Dev server met HMR (Hot Module Replacement): enkel de gewijzigde module vervangen, zonder herladen en zonder state te verliezen
  • Nieuwe tools zijn geschreven in Rust: native en parallel op alle CPU-kernen, 10 tot 30 keer sneller

Voor we naar de cijfers over tooling kijken, moeten we weten wat een build tool doet. De code die jij schrijft, is niet de code die de browser uitvoert. Je schrijft TypeScript en JSX, je importeert honderden modules uit node_modules, en je schrijft CSS in aparte bestanden. Een build tool zet dat om naar iets wat de browser efficiënt kan laden. Dat gebeurt in een aantal stappen. Transpileren: TypeScript en JSX worden omgezet naar gewone JavaScript, want browsers begrijpen geen JSX. Bundelen: honderden kleine modules worden samengevoegd tot een paar bestanden, zodat de browser niet honderden aparte requests moet doen. Tree shaking: code die je importeert maar nooit gebruikt, wordt weggelaten, zoals dode takken die je van een boom schudt. Minificeren: spaties, commentaar en lange variabelenamen worden verwijderd om het bestand kleiner te maken. En code splitting: in plaats van één gigantisch bestand krijgt elke pagina zijn eigen stuk JavaScript, dat pas geladen wordt wanneer je die pagina bezoekt. De rare codes in de bestandsnamen, zoals app-3f9a.js, zijn hashes van de inhoud: verandert de code, dan verandert de naam, en zo weet de browser dat hij een nieuwe versie moet downloaden. Tijdens het ontwikkelen draait er een dev server met Hot Module Replacement: als je een bestand opslaat, wordt alleen die module in de browser vervangen, zonder de pagina te herladen. En waarom worden die tools in Rust herschreven? Omdat Rust gecompileerd wordt naar native machinecode en makkelijk meerdere CPU-kernen tegelijk gebruikt. JavaScript-tools zijn daar veel trager in.
