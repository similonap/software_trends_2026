RC = release candidate, een bijna-stabiele testversie

2

Er bestaat een grappige website, dayssincelastjavascriptframework.com, met een teller die aangeeft hoeveel dagen er verstreken zijn sinds er een nieuw JavaScript-framework uitkwam. Die teller staat zo goed als altijd op nul. Dat is natuurlijk overdreven, maar het tempo is echt hoog. Kijk naar de tabel: op twaalf maanden kregen we een nieuwe grote versie van Next.js, de eerste stabiele React Compiler, twee versies van Angular, een nieuwe versie van de build tool Vite, release candidates van Vue en SvelteKit, en in oktober 2026 nog twee volledig nieuwe frameworks: Remix 3 en TanStack Start 1.0. Een release candidate, afgekort RC, is een versie die bijna klaar is: functioneel compleet, maar nog in testfase. Wat betekent dat voor jullie? Dat het weinig zin heeft om één framework uit het hoofd te leren. Versies en API's veranderen voortdurend. Wat wél blijft, zijn de concepten eronder: hoe wordt HTML gemaakt, waar draait code, hoe weet een framework wat er op het scherm moet veranderen. Wie die concepten begrijpt, kan elk nieuw framework snel leren. Daarom ligt de focus van deze les op die concepten.
