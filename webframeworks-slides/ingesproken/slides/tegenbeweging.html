Tegenover de server-first aanpak van Next.js staat een duidelijke tegenbeweging. Het meest opvallende voorbeeld is Remix 3, dat begin oktober 2026 stabiel werd. Remix was oorspronkelijk een React-meta-framework; OpenAI gebruikte het bijvoorbeeld voor de ChatGPT-website, omdat het sterk is in client-side interactie. Remix werd later samengevoegd met React Router 7. Remix 3 is iets totaal nieuws: het laat React volledig los. Het heeft een eigen UI-runtime, vertrokken van een fork van Preact, een kleine React-achtige library. Je schrijft nog JSX, maar state is gewoon een JavaScript-variabele. Aan de serverkant draait alles rond de standaard Request- en Response-objecten van het web en gewone HTML-formulieren: progressive enhancement. Alles zit in één package met weinig dependencies, wat het team ook als security-argument gebruikt. TanStack Start, van de makers van de populaire libraries TanStack Query en TanStack Router, werd op 13 oktober 2026 versie 1.0. Het is client-first: de browser blijft het centrum van de applicatie, met server side rendering als extra. Het is volledig type-safe: als je een route hernoemt, geeft TypeScript meteen een fout op elke link ernaar. Server Components zijn optioneel. Het TanStack-team schreef zelfs een blogpost met de titel ‘We stopped using RSC on tanstack.com’: de bundle werd kleiner, maar de extra complexiteit woog niet op tegen de winst. En Astro, met zijn islands-architectuur, blijft de favoriet voor content-websites en heeft de hoogste tevredenheid van alle meta-frameworks. De boodschap: Server Components zijn een krachtig hulpmiddel, maar geen universele standaard.
