AGENTS.md en llms.txt

  • AGENTS.md: markdown-bestand in de root van je project met instructies voor coding agents: stack, commando’s, conventies
  • De agent leest het automatisch bij de start
  • llms.txt: bestand op een website (bv. nextjs.org/docs/llms.txt) met een overzicht van de documentatie in platte markdown
  • Makkelijk leesbaar voor een taalmodel
  • Verschil: AGENTS.md staat in jouw project (instructies), llms.txt op een website (documentatie)

# AGENTS.md

## Stack
- Next.js 16 (App Router), TypeScript
- Tailwind CSS, Prisma + PostgreSQL

## Commando's
- npm run dev · npm test · npm run lint

## Conventies
- Server Components standaard;
  'use client' enkel voor interactie
- Valideer input in Server Actions (zod)
- Draai npm test voor je stopt

Twee eenvoudige maar belangrijke conventies om agents de juiste informatie te geven. AGENTS.md is een gewoon markdown-bestand dat je in de root van je project zet. Het bevat instructies voor coding agents: welke technologieën het project gebruikt, welke commando's er zijn om te starten, te testen en te linten, en welke afspraken het team maakt. De meeste coding agents lezen dat bestand automatisch zodra ze in je project beginnen te werken. Je kan het vergelijken met een README, maar dan geschreven voor een nieuwe collega die alles letterlijk neemt. Kijk naar het voorbeeld rechts. Onder Stack staat dat het project Next.js 16 met de App Router gebruikt; daardoor genereert de agent geen oude Pages Router-code. Onder Commando's staat hoe je test, zodat de agent zijn werk kan controleren. En onder Conventies staan teamafspraken: Server Components standaard, input valideren met zod, en altijd de tests draaien voor je stopt. Een kort, concreet bestand werkt beter dan een lang document. Sommige tools gebruiken een eigen bestandsnaam, zoals CLAUDE.md voor Claude Code, maar het principe is hetzelfde. llms.txt is een conventie voor websites: een bestand op een vaste plek, slash llms.txt, met een overzicht van de documentatie in platte markdown, zonder menu's, reclame of JavaScript. Een taalmodel kan dat veel efficiënter lezen dan een gewone webpagina. Next.js biedt het aan, en je kan bij elke documentatiepagina .md achter de URL plakken om de markdown-versie te krijgen. Het verschil: AGENTS.md staat in jouw project en bevat instructies; llms.txt staat op de website van een framework en bevat documentatie.
