Om de security-incidenten te begrijpen, overlopen we eerst een aantal begrippen. Het aanvalsoppervlak, in het Engels attack surface, is de som van alle plaatsen waar een aanvaller input kan geven aan je systeem: API-endpoints, formulieren, file uploads, headers. Hoe meer code er op een server publiek bereikbaar is, hoe groter het aanvalsoppervlak. Een kwetsbaarheid is een fout in software die misbruikt kan worden. Een exploit is de concrete code of het concrete request dat die fout effectief misbruikt. Een CVE, wat staat voor Common Vulnerabilities and Exposures, is een uniek nummer dat aan een publiek bekende kwetsbaarheid wordt gegeven, zodat iedereen weet over welk lek het gaat. Het nummer bevat het jaartal en een volgnummer. CVSS, het Common Vulnerability Scoring System, geeft een ernstscore van nul tot tien. Daarbij wordt gekeken naar hoe makkelijk het lek te misbruiken is, bijvoorbeeld of je moet ingelogd zijn, en wat de impact is. Alles vanaf negen is kritiek. RCE, remote code execution, betekent dat een aanvaller van op afstand zijn eigen code op jouw server kan uitvoeren. Dan kan hij alles: data stelen, de database leegmaken, malware installeren. Dat is het ergste wat er kan gebeuren. DoS, denial of service, betekent dat een aanvaller je server zo zwaar belast dat hij niet meer antwoordt voor gewone gebruikers. Een patch is een update die een lek dicht. Belangrijk: een patch beschermt je pas als je hem ook installeert. En een zero-day is een lek dat al misbruikt wordt voordat de makers er een patch voor hebben.
