Angular 21 en 22

  • Zoneless standaard (v21, november 2025): geen zone.js meer in nieuwe projecten
  • OnPush standaard (v22): de oude strategie heet nu Eager
  • Signal Forms: model, waarden en validatie van een formulier zijn signals
  • resource(): asynchrone data (bv. HTTP) als signal met value, isLoading en error
  • @Service(): korte schrijfwijze voor een service die je met inject() ophaalt

@Service()
export class UserApi {
  http = inject(HttpClient);
}

export class Signup {
  model = signal({ email: '' });
  form = form(this.model, (f) => {
    required(f.email);
    debounce(f.email, 'blur');
  });
  valid = computed(() =>
    this.form().valid());
}

Angular is het duidelijkste voorbeeld van de eerste trend. De eerste twee punten hebben we net in detail gezien: zoneless is de standaard sinds Angular 21, OnPush sinds Angular 22. Maar er veranderde meer. Daarnaast werden twee nieuwe API's stabiel die volledig op signals gebouwd zijn. Signal Forms: een formulier waarbij het model, de ingevulde waarden en de validatiestatus allemaal signals zijn. Je ziet het in de code: het model is een signal met een e-mailadres, het formulier wordt daarop gebouwd met een validator required en een debounce, wat betekent dat er pas gevalideerd wordt als je het veld verlaat. En de resource-API: daarmee haal je asynchrone data op, bijvoorbeeld via HTTP, en krijg je een signal terug met de waarde, of hij nog aan het laden is en of er een fout was. Tot slot de @Service-decorator: een kortere schrijfwijze voor een service. Een service is in Angular een klasse met gedeelde logica, bijvoorbeeld voor API-calls, die je via dependency injection in componenten gebruikt. Dependency injection betekent dat een component zijn afhankelijkheden niet zelf aanmaakt, maar ze vraagt aan het framework, hier met inject(HttpClient). Het resultaat: Angular is geëvolueerd van een framework met veel verborgen magie, zoals zone.js, naar een van de meest expliciete frameworks. Dat expliciete komt ook AI-agents ten goede, zoals we in trend vier zullen zien.
