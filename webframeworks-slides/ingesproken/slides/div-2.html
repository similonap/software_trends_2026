Trend 2

Terug naar de server

Server-first blijft, maar het moet aanvoelen als een SPA

37

Trend twee gaat over de slinger tussen server en client. In de begindagen van het web werd alles op de server gerenderd, denk aan PHP. Rond 2015 zwaaide de slinger naar de client: single page applications met React, Angular en Vue. De laatste jaren zwaaide hij terug naar de server, met server side rendering en Server Components, sterk gepusht door Next.js. Dit jaar zien we iets nieuws: de server-first frameworks erkennen zelf dat server-gerenderde apps trager kunnen aanvoelen dan SPA's, en proberen het beste van beide werelden te combineren. Tegelijk is er een tegenbeweging van frameworks die bewust minder op de server inzetten. Om dat te begrijpen, hebben we twee nieuwe kernbegrippen nodig: hoe navigatie werkt, en wat caching is.
