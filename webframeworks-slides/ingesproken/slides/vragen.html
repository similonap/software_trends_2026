Daarmee zijn we aan het einde. Zijn er vragen? Als er geen vragen komen, start ik graag een korte discussie: zou jij een framework kiezen op basis van wat je AI-agent het best kent? Met andere woorden: is het een geldig argument om voor React te kiezen omdat modellen daar het meest over weten, ook al past Svelte of Angular misschien beter bij je project? Er is geen juist antwoord, maar teams stellen die vraag in 2026 echt. Andere mogelijke discussievragen: Moet een framework automatisch een AGENTS.md in jouw project mogen schrijven? Wat vind je ervan dat bijna elk groot framework eigendom is van, of gefinancierd wordt door, een cloud- of AI-bedrijf? En: als een agent 1.500 issues kan triëren, wat betekent dat voor de rol van een open source maintainer? Rechts staan de belangrijkste bronnen. Alle cijfers in deze presentatie komen daaruit; waar een cijfer uit een secundaire bron komt of eerder een observatie uit de praktijk is, heb ik dat vermeld. Bedankt voor jullie aandacht.
