Zo ziet de les eruit. We beginnen met de vraag wat een framework en een meta-framework precies zijn, en kijken naar een paar cijfers over het landschap in 2026. Daarna volgt het belangrijkste theoretische blok: de bouwstenen. Hoe wordt een webpagina gerenderd: in de browser, op de server of tijdens de build? Wat is hydration? Wat zijn server components? En hoe weet een framework wat er op het scherm moet veranderen als de data verandert: virtual DOM, signals of een compiler? Met die bouwstenen in de hand bespreken we vijf trends. Eén: signals en compilers zijn de standaard geworden. Twee: de discussie over wat op de server en wat in de browser hoort, en hoe frameworks het beste van beide proberen te combineren. Drie: security, want code op de server brengt nieuwe risico's mee. Vier: de AI-agent als nieuwe gebruiker van frameworks. Vijf: hoe AI het web zelf verandert. Een praktische tip: slides met het woord Kernbegrip rechtsboven bevatten de definities die je moet kennen. Voor elk begrip krijg je een definitie, hoe het werkt, een voorbeeld en de voor- en nadelen. Op de andere slides zie je hoe die begrippen in de praktijk terugkomen in concrete frameworks.
