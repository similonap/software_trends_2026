Een model kent het framework van gisteren

Frameworks veranderen elk kwartaal. De trainingsdata van een model loopt maanden tot jaren achter.

Typische fouten:

  • getServerSideProps (oude Pages Router) in een App Router-project
  • middleware.ts in plaats van proxy.ts
  • NgModules in Angular
  • useMemo overal

AGENTS.md, automatisch geschreven door next dev (16.3):

# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in node_modules/next/dist/docs/ before writing any code. Heed deprecation notices.

Bron: nextjs.org/blog/next-16-3-ai-improvements (26/06/2026)

Hier zit het fundamentele probleem: een taalmodel heeft een training cutoff, en frameworks veranderen elk kwartaal. Bovendien heeft een model vooral gezien wat veel op het internet stond, en dat zijn oudere tutorials en Stack Overflow-antwoorden. Een voorbeeld. In oudere versies van Next.js haalde je data op met een functie getServerSideProps, in de zogenaamde Pages Router. Die manier is al jaren vervangen door de App Router en Server Components. Maar omdat er zoveel tutorials over bestaan, genereren AI-modellen die oude code nog vlot, ook in projecten waar ze niet werkt. Hetzelfde met middleware.ts, dat in Next.js 16 hernoemd werd naar proxy.ts. Of in Angular: modellen genereren NgModules en constructor injection, terwijl moderne Angular standalone componenten, inject() en signals gebruikt. Kijk naar de oplossing van Next.js rechts. Sinds versie 16.2 zit de volledige documentatie in het npm-package zelf, in de map node_modules. Zo is de documentatie altijd exact die van de versie die je gebruikt. En sinds 16.3 schrijft het commando next dev automatisch een blok tekst in het bestand AGENTS.md, als het merkt dat er een AI-agent actief is. De tekst is bijna grappig: ‘This is NOT the Next.js you know’. Deze versie heeft breaking changes, de API's kunnen verschillen van je trainingsdata, lees eerst de juiste gids voor je code schrijft. Dat is een fundamentele verschuiving: documentatie wordt niet alleen geschreven voor mensen die een website bezoeken, maar ook voor agents, versie-specifiek, lokaal in je project. Wat AGENTS.md precies is, zien we op de volgende slide.
