Begrippenlijst (3/3): server, security en AI

Caching: resultaat bewaren om het niet opnieuw te berekenen; risico op verouderde data

Prefetching: code of data al ophalen vóór de gebruiker klikt

Islands: statische pagina; enkel interactieve eilanden krijgen JavaScript

Progressive enhancement: werkt met HTML, JavaScript is een verbetering

Server Action: server-functie aangeroepen vanuit de client; is een publiek HTTP-endpoint

(De)serialisatie: object ↔ tekst/bytes om te versturen; gevaarlijk bij onbetrouwbare input

CVE / CVSS: uniek nummer per lek / ernstscore van 0 tot 10

RCE: een aanvaller voert eigen code uit op jouw server

Supply chain attack: aanval via een dependency in plaats van via je eigen code

Coding agent: LLM in een lus met tools: lezen, aanpassen, uitvoeren, herhalen

AGENTS.md / llms.txt: instructies in je project / docs in markdown op een website

MCP / skill: standaard om tools aan AI te koppelen / stappenplan dat op aanvraag laadt

Prompt injection: verborgen instructies in data die een AI-model uitvoert

WebMCP / MCP Apps: webpagina biedt tools aan agents / chat toont interactieve web-UI

De tweede helft van de begrippenlijst, met de begrippen uit trend twee tot vijf: navigatie en caching, security en AI. Let vooral op de verbanden tussen begrippen. Een Server Action is een publiek HTTP-endpoint waarvan de argumenten geserialiseerd worden; een fout in de deserialisatie kan leiden tot RCE, zoals bij React2Shell met CVSS-score tien. Een coding agent gebruikt AGENTS.md voor kennis, skills voor workflows en MCP voor live informatie, en is kwetsbaar voor prompt injection, waartegen je je beschermt met least privilege, een sandbox en een mens die controleert. Wie die verbanden kan uitleggen, begrijpt de trends van 2026, en zal ook de trends van 2027 snel kunnen plaatsen.
