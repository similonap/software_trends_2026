# Software Trends: labo web frameworks

Labo voor het vak Software Trends (AP Hogeschool, 2026–2027), bij de les *Trends in JavaScript web frameworks*.

In 120 minuten werken studenten met de **React Compiler**, **zoneless Angular** en **Next.js 16**, en gebruiken ze daarbij verplicht een **coding agent** naar keuze.

De opgave staat in [`labo/webframeworks/`](../labo/webframeworks/README.md): de planning, de voorbereiding, drie startprojecten met elk een `OPDRACHT.md`, en een verslagsjabloon.

Elk project start je met `npm install` in zijn eigen map. Je hebt Node.js 22.12 of nieuwer nodig.
